A simple tool that acts as a personal weather reporter for your location.

The built binaries use the llama3.2 model as it is small (only 2gb) and works fine for this task, feel free to go into the code and change the model on line 105 and rebuild it.

*NOTE* You NEED Ollama to be running locally in the background for this to work as this uses ollama to run an LLM to act as your personal weather reporter.
